# 作業記録 [9/10(1)]

### 1. 調査した内容
- バグ：トップ画面で都道府県を指定して施設一覧へ遷移した後,施設詳細画面や新規登録画面に移動してから「← 施設一覧に戻る」を押すと,フィルターが解除されて全件一覧ページ（/facilities）に戻ってしまう
- 原因：各画面への遷移時にurlのクエリパラメータ（prefectureId）を引き継いでおらず,各コンポーネントsearchParamsからprefectureIdを取得できていなかった.

### 2. 悩み・疑問
- 施設詳細画面側でbackUrlの条件分岐を記述していたものの,一覧画面からのリンクに?prefectureId=XXが付与されていなかったため,常にundefinedと判定されて全件一覧へ遷移していた.

### 3. 学習した内容
- 自分は画面遷移する際は移動したいページのpathを渡せばいいと考えていたのですが,今回のように条件を絞り込んだ後の状態のページへリダイレクトする際は前の段階でキーとなる値を受け渡す必要があることを学習した.
- 

### 4. 設計
- 画面間データ共有のフロー:
    - トップ画面：router.push('/facilities?prefectureId=XX')
    - 施設一覧画面：searchParamsからprefectureIdを取得し,詳細画面および新規作成画面の<Link>に?prefectureId={prefectureId}を動的付与.
    - 施設詳細画面：searchParamsからprefectureIdを取得し、戻り先（backUrlを/facilities?prefectureId=${prefectureId}に設定.
    - 新規施設登録画面：同様にprefectureIdを引き継ぎ、戻り先およびフォームの都道府県初期値に反映.

### 5. 仕様
- 各種登録フォーム欄の任意部分の項目を追加
- 施設一覧表示画面と施設詳細画面のファイルをそれぞれprefectureIdを受け渡して画面遷移できるように変更した
