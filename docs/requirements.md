# 温泉ログアプリ 要件定義書

## プロジェクト概要
開発者自身が趣味とする温泉巡りの体験を構造化し、一元管理・可視化するための専用Webアプリを構築する。温泉データ（料金、評価、感想など）を蓄積し、後から検索・振り返りを容易にすることを目的とする。

-   **ターゲット:** 温泉巡りを趣味とする人
-   **提供価値:** 日本地図を通じた視覚的な記録の蓄積と、過去の訪問履歴の迅速な検索・振り返り。
-   **技術的目標:** Next.js、PostgreSQL、Dockerを活用したフルスタック開発スキルの実証。

## 機能要件 (MVP版)
-   **日本地図ナビゲーション機能:**
    トップ画面に日本地図を表示。都道府県を選択すると、該当エリアの登録済み温泉一覧画面へ遷移する。
-   **施設一覧・ソート機能:**
    選択エリアの温泉をカード型UIで一覧表示。ユーザーの操作により「評価順（降順）」「料金順（昇/降順）」「登録順（降順）」に表示を即座に切り替えられる。
-   **温泉記録の新規登録機能:**
    一覧画面からの導線で、新たに訪れた温泉のデータおよびレビューを登録できる。

## 登録フォーム項目定義
| 項目名 | 入力形式 | 必須/任意 | 備考 |
| :--- | :--- | :--- | :--- |
| 施設名 | テキスト | 必須 | 例: 〇〇の湯 |
| 住所 (都道府県) | 選択＋テキスト | 必須 | 地図UIとの連動キー |
| 訪れた日 | カレンダー選択 | 必須 | デフォルトは当日 |
| 利用料金 | 数値 (円) | 任意 | 料金ソート機能に使用 |
| レビュー評価 | 星評価 (1〜5) | 必須 | 評価ソート機能に使用 |
| レビュー感想 | テキストエリア | 任意 | 泉質、混雑度などのメモ |
| 施設画像 | 画像アップロード | 任意 | 一覧画面用のサムネイル |
| 施設HP URL | URLテキスト | 任意 | 外部リンクとして保持 |

## 非機能要件
*   **パフォーマンス:** 一覧表示のソート切り替えや画像読み込みにおいて、ユーザーの操作を阻害しないレスポンス速度を確保する。
